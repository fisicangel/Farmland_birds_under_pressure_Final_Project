# EU Farmland Birds Under Pressure

Interactive HTML presentation based on Eurostat farmland-bird data and the accompanying machine-learning study.

## Open locally

Open `index.html` in a browser. The charts and presentation navigation work without a server. The embedded Tableau dashboard requires an internet connection.

## Publish with GitHub Pages

1. Upload all files in this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.

The presentation will normally appear at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Files

- `index.html`: presentation structure, styling and interactions
- `data.js`: Eurostat bird-index time series used by the interactive charts
- `linnet.webp`: cover photograph, credited in the presentation to Pete Godfrey / Unsplash
- `favicon.svg`: browser-tab icon
